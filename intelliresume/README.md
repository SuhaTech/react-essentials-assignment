# IntelliResume

An AI-powered resume analysis platform that helps users improve their resumes with ATS analysis, AI assistance, and resume optimization.

---

## 🚀 Features

- AI Resume Analysis
- ATS Score Analysis
- Resume Upload
- AI Chatbot
- Responsive UI
- Secure Authentication
- Modern Dashboard

---

## 🛠 Tech Stack

### Frontend
- React.js
- Vite
- Tailwind CSS
- React Router DOM
- Lucide React

### Backend
- Node.js
- Express.js

### Database
- MongoDB

## 📦 Installation

Clone the repository

```bash
git clone <repository-url>
```

Go to the project folder

```bash
cd intelliresume
```

Install dependencies

```bash
npm install
```

Start development server

```bash
npm run dev
```
