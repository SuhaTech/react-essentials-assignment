Project Title: User Signup & Pizza Ordering Application

Tech Stack: React.js, Redux Toolkit, React-Redux, CSS3 / Responsive Layouts

Project Overview:
This application is a production-ready, multi-page workflow platform designed to handle complex global state management using Redux Toolkit. It comprises two main operational modules:

User Signup Flow: Manages registration fields (Full Name, Email, Phone, Password, Gender, Terms) using userSlice. Includes real-time validation, error dispatching, form resets, and submission state tracking.

Interactive Pizza Builder & Cart System: Driven by pizzaSlice and cartSlice. Features dynamic pricing based on size and topping selections, live order previews, item quantity modifications, and global shopping cart state updates.

Key Features & Architecture:

Centralized Store & Modular Slices: Cleanly separated concerns across userSlice, pizzaSlice, cartSlice, and uiSlice.

Dynamic UI & Form Logic: Real-time price auto-calculation, conditional topping availability, and responsive UI reactions based on user choices.

Responsive Design: Optimized layout for Desktop, Tablet, and Mobile screens.

Submission Compliance: Prepared clean source code without node_modules and included mandatory responsiveness screenshots.
