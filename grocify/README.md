# Grocify Clone

A responsive grocery website homepage built using React.js and Tailwind CSS.

## Features

- Responsive Navbar
- Hero Section
- Categories
- Product Cards
- Offer Banner
- Testimonials
- Newsletter
- Footer
- Responsive Design
- Framer Motion Animations

## Tech Stack

- React
- Tailwind CSS
- React Icons
- Framer Motion

## Run Project

npm install

npm run dev
