# Task Manager Application

A simple Task Manager built using React, Context API, and useReducer.

## Features

- Add Task
- Edit Task
- Delete Task
- Mark Task Complete
- Clear All Tasks
- Task Summary
- Responsive UI
- Global State Management using Context API
- State Updates using useReducer

## Technologies Used

- React
- Context API
- useReducer
- CSS

## Folder Structure

src/
├── components
├── context
├── reducer
├── styles
├── App.jsx
└── main.jsx

## How to Run

```bash
npm install
npm run dev
```
