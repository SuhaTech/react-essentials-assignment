# 🎓 Student Grade Tracker

A React application built using **Class-Based Components** and **React Lifecycle Methods**.

## 🚀 Features

- Add Student
- Update Student Grade
- Delete Student
- Grade Validation (0-100)
- Pass / Fail Status
- Filter Passed Students
- Sort Students by Grade
- Responsive UI
- Lifecycle Methods Demonstration

## 📚 Concepts Used

- Class Components
- constructor()
- super()
- this.state
- this.setState()
- componentDidMount()
- componentDidUpdate()
- componentWillUnmount()
- Props
- Controlled Forms
- Event Handling
- Conditional Rendering

## 🛠️ Technologies

- React
- CSS3
- JavaScript (ES6)

## ▶️ Installation

```bash
npm install
npm run dev
```
